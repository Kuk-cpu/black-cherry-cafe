## 验证范围

单元测试覆盖全部 68 个商品默认选项及每项加价计算、澳分整数运算、上下架标志一致性、档期边界、筛选搜索、三方菜单合并、历史状态转换、图片文件及生产配置校验。

Firebase 集成覆盖数据库权限、匿名写入拒绝、顾客订单投影访问、服务端金额校验、并发重复提交去重、关店和售罄拒单、角色权限、最后管理员保护、图片路径审核、合法状态流转、付款校验、实时投影、一单一评及限流。

浏览器验收覆盖：

1. 68 个商品独立本地插画、4:3 比例、alt、详情图及顾客文案。
2. 全部筛选及描述搜索。
3. WebP 失败时加载同商品 SVG，仍能点单。
4. 后台饮食标签和新品截止时间编辑。
5. 手机顾客选择燕麦奶与加浓、刷新保留购物车、提交 $6.60 订单；员工接单、付款、制作、出餐、完成；顾客实时跟踪及反馈。
6. 管理员价格编辑和恢复、售罄、二维码 PNG/SVG 下载、A6 打印及 CSV 导出。
7. 匿名 API 权限与 375 / 768 / 1440px 布局。
8. 售罄、恢复、下架、重新上架同步到已打开的顾客页面。
9. 员工取消订单后，顾客即时接收取消状态，刷新仍保留。
